# Kubernetes Deployment & Monitoring on Google Cloud

This repository demonstrates deploying an LLM-based application on **Google Cloud VM infrastructure** using **Docker, Minikube, and Kubernetes**, with full **observability via Prometheus and Grafana**.

The project focuses on real-world cloud-native deployment and monitoring practices.

---

## 🚀 Key Highlights

- Application containerization using Docker
- Kubernetes deployment using Minikube on GCP VM
- Secure secret management with Kubernetes Secrets
- GitHub-based source control and VM integration
- Application exposure via Kubernetes services
- Monitoring and observability using Prometheus & Grafana

---

## 🛠️ Tech Stack

- Python / Flask
- Docker
- Kubernetes (Minikube)
- Google Cloud Platform (Compute Engine VM)
- Prometheus
- Grafana
- GitHub
